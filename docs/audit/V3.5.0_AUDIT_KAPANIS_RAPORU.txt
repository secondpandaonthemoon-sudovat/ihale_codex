KONTROLLÜ MİMARİ KALINTILAR
A) app_state halen geriye uyumluluk için canonical compatibility kaynağıdır. V3.5.0 full-state yazımı azaltıp delta PATCH kullanır. Tam tablo-canonical migrasyon, ayrı major veri migrasyonu olarak yapılmalıdır.
B) JavaScript index.php'den assets/js/app.js'e çıkarıldı ancak tam domain bazlı modül ayrımı (requests/suppliers/finance vb.) ayrı refactor olarak kalır.
C) Legacy HTML template'lerde inline onclick/onchange bulunduğu için CSP script-src içinde unsafe-inline halen gerekir. Server/client sanitization ve diğer CSP kısıtları aktif; strict nonce/event-delegation dönüşümü ayrı UI migrasyonudur.

Bu üç konu aynı production stabilizasyon paketinde zorla dönüştürülmedi; veri/iş akışı regresyon riski, sağlayacağı kısa vadeli faydadan daha yüksektir.
